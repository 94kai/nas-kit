# nas-kit

个人自用工具仓库，包含两个相互独立的项目：

- **[dsh-plugin](dsh-plugin/README.md)**：随身工具箱 · Pocket Kit，DSH 插件（`@local/pocket-kit`），功能入口在 DSH GUI 的工具箱中。
- **[fn-aio](fn-aio/README.md)**：FN AIO，飞牛（fnOS）上的独立 App 与私有服务网关，以 FPK 安装。

两者共享 Git 仓库，但运行环境、安装方式与安全边界彼此独立，不互相依赖。

仓库结构、路径约定、常用命令和边界说明见 [AGENTS.md](AGENTS.md)；各项目的功能与开发细节见各自的 README 和 `docs/`。
