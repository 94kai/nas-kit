# 修图工作台

会话绑定的照片批处理面板。一个会话对应一个照片目录，面板只做「清单 + 展示 + 渲染」；判断、解释和写参数都发生在会话里，由 Agent 调用 `photo_lab` 工具完成。

## 用法

1. 在会话右上角点「修图」，输入照片目录的绝对路径，点「打开」（首次会生成缩略图，36 张大约十几秒）。
2. 点「初筛」：面板会往会话里发一条请求，Agent 生成联系表、逐格判断、把结论写回清单。
3. 在网格里拍板：全选、全不选、单张「修这张 / 跳过」，也可以写批注让 AI 按你的话调整。
4. 选风格（自然通透 / 暖调胶片 / 冷调电影 / 日系清淡 / 黑白），点「修选中的」。
5. 点开任意一张：拖动分割线对比前后，`+ / − / 1:1` 缩放，批注后「应用」进入下一轮。
6. 导出：点工具栏「导出」（或让 Agent 调 `photo_lab` 的 export），压缩包写到照片目录下的 `_export/`。

## 批注

- 每张可以写一段批注，先「保存」（存在清单里，不影响修图），再决定什么时候「执行」。
- 执行会把批注作为一条消息发给会话；批注里可以是修改要求，也可以是问题——AI 会先判断，是提问就直接回答，不一定要修图。
- 工具栏的「执行批注 N」一次把还没执行的批注全部发出去。

## 局部调整与外部回写

- `grade` 支持 `local` 遮罩（radial/linear/box/polygon），可做聚光灯、压天空、局部提亮；`mask_preview:true` 会额外输出红色遮罩自检图。
- `retouch` 先 `auto` 拿污点点位，确认后带 `spots` 才出图。
- `ingest` 把外部修好的图回写成一整轮；`set_final` 后导出优先用它。
- 每轮记录完整参数（style/adjust/local/crop/width）和直方图统计。

## 版本

每修一次新增一轮（v1、v2…）。单张详情里有版本条，点哪个就对比哪个版本；每轮都带同裁切的对齐原图，切换时构图不会跳。

## 状态与导出

- `keep` 保留、`skip` 跳过、`delete` 标删；`delete` 表示连原图都不要了。
- 「导出」打一个 zip 到照片目录的 `_export/`：修过的只放修后图（`修好的/`），没修过的放原图（`原图/`），标删的不进包；包里附 `说明.txt`。
- 「清理标删」需要点两次确认，才会把标删的原图从目录里真正删掉（不可恢复），清单里记 `missing` + `deletedAt`。
- 初筛只写 `triage`，用户改过的 `decision` 不会被覆盖。

## 数据

- 项目清单：`~/.dsh/photo-lab/projects/<id>/project.json`
- 缩略图、预览、修后图：同目录的 `thumbs/`、`previews/`、`out/`
- 会话绑定：`~/.dsh/photo-lab/bindings.json`
- 原照片只读，不修改；导出只写 `_export/`，清理标删是唯一会动原图的动作。

## 边界

只做参数化调色与裁切（曝光、对比、白平衡、饱和、五种风格、暗角、锐化），不做换天、去人、生成细节。照片在模型侧做初筛时会上传缩略图。

## 未验证

安装与 Host 路由、渲染引擎在开发机验证；面板在真实页面里的布局、触摸拖动、暗色主题需要刷新 GUI 后人工确认。
