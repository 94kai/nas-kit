# 文件 · @local/files

这是独立的 DSH Web 插件。点左侧栏「文件」打开运行 DSH 的系统账号的主目录（`~`），不随当前会话切换工作区。文件页从面包屑开始，不另设返回会话栏或目录标题栏。

- 点文件夹进入；左右滑动单行面包屑，点任一祖先即可返回，包括主目录的上一级和文件系统根 `/`。默认隐藏名字以 `.` 开头的项目，开启「显示隐藏文件」后，浏览列表和移动时的目录选择器都会显示它们。
- 从工具栏的收藏入口收藏当前位置，也可从行尾 `…` 收藏文件夹。「收藏」中点目录名即可直达。收藏与隐藏偏好保存在当前浏览器，不会自动跨设备同步。
- 点文件名打开预览。Markdown、文本、常见图片以及浏览器能解码的音频和视频可直接查看；可下载原文件。不转码，不把文档当网页执行。
- 行尾 `…` 可重命名、移动或删除。移动选择目标文件夹后点「移动到这里」。同名不覆盖；删除文件夹会递归**永久删除**其内容，不进回收站。通过本页面移动、重命名或删除目录会同步更新当前浏览器中的收藏。

## 文件与权限

插件使用 DSH Connection 的所有者鉴权，提供自有 `/api/local-files/` 接口，不另开端口，也不提供 Agent 工具。`list`、`text`、`rename`、`move`、`delete` 接受带 `X-Local-Files: 1` 的 JSON POST；`content` 用同源 GET/HEAD 读取，支持字节 Range 与 `download=1`。列表返回当前绝对路径、主目录绝对路径及各项的绝对路径；空路径仍指向 home。可按服务账号的系统权限浏览和管理文件，包括 home 外的数据盘，不跟随符号链接，也不开放 `/proc`、`/sys`、`/dev`。文件系统根、home 及其上级目录本身不可重命名、移动或删除；这不妨碍管理这些目录下的普通项目。隐藏开关是展示偏好，不是访问控制；应像管理主目录一样保护 DSH 所有者登录凭据。

文本预览支持 1 MiB 以内的 UTF-8 文件；单个目录最多列出 10,000 个可见项目。递归删除不会跨入子挂载点，若遇权限或挂载限制会停止，已删除的项目不会回滚。

当前面向 Linux，使用 `/proc/self/fd` 锚定目录，重命名和移动依赖 Python 3、libc 的 `renameat2` 和文件系统的禁止覆盖支持；不支持跨文件系统移动。

## 开发与安装

在此目录运行 `npm run build` 生成单文件客户端，无第三方构建依赖。通过 DSH 插件管理器安装本目录，不需要安装整个 Pocket Kit。已用插件源码目录只读核对列表、文本和 Range；隐藏切换、重命名、同名保护、移动、递归删除和根目录保护仅在隔离临时目录核对。未做浏览器或真机交互验收，未对真实私人文件演练写操作。
